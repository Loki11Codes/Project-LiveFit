# Contributing to LiveFit

First off, thanks for taking the time to contribute! It's people like you that make LiveFit better for everyone.

## Code of Conduct

Help us keep LiveFit a welcoming and inclusive community. Please be respectful and constructive in all interactions.

## How Can I Contribute?

### Reporting Bugs
- Use the [Bug Report](https://github.com/Loki11Codes/Project-LiveFit/issues/new?template=bug-report.yml) template.
- Provide a clear description and steps to reproduce.

### Suggesting Features
- Use the [Feature Request](https://github.com/Loki11Codes/Project-LiveFit/issues/new?template=feature-request.yml) template.
- Explain the problem you're trying to solve and your proposed solution.

### Pull Requests
1. Fork the repository.
2. Create a new branch for your feature or fix.
3. Write clear, documented code.
4. Ensure all tests pass.
5. Submit a pull request with a detailed summary of your changes.

## Development Setup

1. Clone the repository.
2. Install dependencies: `npm install`
3. Set up your environment variables (see `.env.example`).
4. Run the dev server: `npm run dev`

## Coding Standards
- Use TypeScript for all new code.
- Follow the existing project structure.
- Write clean, readable, and well-commented code.
- Ensure your changes don't break existing functionality.

Thanks for contributing!
